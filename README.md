# 🤝 HelpingHand

**HelpingHand** is a community-driven food donation platform that connects food donors with verified NGOs. Donors can list surplus food, and approved NGOs can browse available listings and coordinate pickups — reducing food waste and fighting hunger.

---

## 📁 Project Structure

```
HelpingHand/
├── mainweb/          # Main user-facing application
│   ├── client/       # React frontend (port 3000)
│   └── server/       # Express API backend (port 5000)
│
└── admin/            # Admin panel (separate app)
    ├── client/       # React frontend (port 3001)
    └── server/       # Express API backend (port 5001)
```

---

## ✨ Features

### Main Web App (Users & NGOs)
- 🔐 **Auth** — Register & login with mobile number + password (JWT-based)
- 🍱 **Donate Food** — List surplus food with details: name, quantity, type (veg/non-veg), availability time, and address
- 📋 **Dashboard** — Browse all available food listings across the platform
- 🔍 **Food Detail** — View full details of a listing and coordinate pickup
- 🗂️ **My Donations** — Track and manage your own food listings
- 👤 **Profile** — View and edit personal information
- 🏢 **NGO Registration** — Apply for NGO status; get reviewed and approved by admins
- ⏰ **Auto-Expiry** — A cron job automatically marks listings as `expired` past their availability time

### Admin Panel
- 🔑 **Admin Login** — Secure single-admin authentication
- 📊 **Dashboard** — Overview of platform activity and stats
- ✅ **NGO Verification** — Review, approve, or reject NGO applications
- 👥 **User Accounts** — Browse and manage all registered users
- 🔒 **Change Password** — Securely update admin credentials

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v18+
- [MongoDB](https://www.mongodb.com/) running locally or a connection URI

---

### 1. Clone the Repository

```bash
git clone https://github.com/ronitmotivaras/HelpingHand.git
cd HelpingHand
```

---

### 2. Set Up the Main Web Server

```bash
cd mainweb/server
cp .env.example .env
# Edit .env with your values (see below)
npm install
npm run dev
```

**`mainweb/server/.env`**
```env
PORT=5000
MONGO_URI=mongodb://127.0.0.1:27017/helpinghand
USER_JWT_SECRET=replace_with_a_long_random_secret
```

---

### 3. Set Up the Main Web Client

```bash
cd mainweb/client
cp .env.example .env
npm install
npm start
```

The main app will be available at **http://localhost:3000**.

---

### 4. Set Up the Admin Server

```bash
cd admin/server
cp .env.example .env
# Edit .env with your values (see below)
npm install

# Hash your admin password first:
npm run hash-password

npm run dev
```

**`admin/server/.env`**
```env
PORT=5001
MONGO_URI=mongodb://127.0.0.1:27017/helpinghand
ADMIN_JWT_SECRET=replace_with_a_long_random_admin_secret
ADMIN_PASSWORD=replace_with_a_strong_admin_password
ADMIN_PASSWORD_HASH=   # paste the hash generated by hash-password script
```

---

### 5. Set Up the Admin Client

```bash
cd admin/client
cp .env.example .env
npm install
npm start
```

The admin panel will be available at **http://localhost:3001**.

## 🗄️ Data Models

### User
| Field | Type | Notes |
|---|---|---|
| `name` | String | Required |
| `mobile` | String | Unique, used as login identifier |
| `passwordHash` | String | bcrypt hashed |
| `city` | String | Required |
| `ngoStatus` | Enum | `none` \| `pending` \| `approved` \| `rejected` |
| `ngoDetails` | Object | NGO name, address, city, contact |

### FoodDonation
| Field | Type | Notes |
|---|---|---|
| `donorId` | ObjectId | Reference to User |
| `donorName` | String | — |
| `donorPhone` | String | — |
| `foodName` | String | — |
| `quantity` | String | — |
| `foodType` | Enum | `veg` \| `nonveg` |
| `availableUpto` | Date | Listing expires after this |
| `address` / `city` | String | Pickup location |
| `status` | Enum | `available` \| `accepted` \| `picked_up` \| `expired` |

## 🔌 API Overview

### Main Web API (`http://localhost:5000`)

| Method | Endpoint | Description |
|---|---|---|
| POST | `/api/auth/register` | Register a new user |
| POST | `/api/auth/login` | Login and receive JWT |
| GET | `/api/donations` | List available food donations |
| POST | `/api/donations` | Create a new donation listing |
| GET | `/api/donations/:id` | Get a single donation's details |
| PATCH | `/api/donations/:id` | Update donation status |
| DELETE | `/api/donations/:id` | Delete a donation |
| GET | `/api/profile` | Get current user's profile |
| PATCH | `/api/profile` | Update profile |
| POST | `/api/profile/apply-ngo` | Submit an NGO application |
| GET | `/api/health` | Health check |

### Admin API (`http://localhost:5001`)

| Method | Endpoint | Description |
|---|---|---|
| POST | `/api/auth/login` | Admin login |
| GET | `/api/users` | List all users |
| PATCH | `/api/users/:id/ngo-status` | Approve or reject NGO application |
| GET | `/api/health` | Health check |
